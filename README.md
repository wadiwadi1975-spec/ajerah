# تطبيق «أُجْرَه» (Ajarah)

منصة توصيل ركاب داخل الجغرافيا السورية، تحاكي فكرة تطبيق أوبر (Uber) ولكن مخصّصة للمدن والطرق السورية.

## الهدف
- ربط الركاب بالسائقين داخل سوريا.
- حساب المسافات والأجور بناءً على جغرافيا المدن السورية (دمشق، حلب، حمص، حماه، اللاذقية، إدلب، درعا، دير الزور، الرقة، الحسكة، القامشلي، طرطوس، السويداء، القنيطرة...).
- واجهة عربية RTL مريحة.

## الحالة الحالية
نموذج أولي (Prototype) بصفحة ويب بسيطة لعرض فكرة التطبيق. سيتم لاحقاً تحديد التقنية النهائية (تطبيق جوال Flutter/React Native، أم موقع ويب).

## التشغيل
افتح ملف `index.html` في المتصفح.

## تسجيل السائقين (الأساس)
صفحة `register.html` هي الأساس لتسجيل السائق لمركبته، وتتحقق من الشروط التالية:

### شروط السائق
1. العمر 21 سنة فأكثر.
2. رخصة قيادة سارية مضى عليها سنة على الأقل.
3. بطاقة شخصية/هوية سورية سارية.
4. سجل أمني نظيف (إفادة بعدم وجود سوابق).
5. صورة شخصية واضحة وحديثة.
6. اجتياز المقابلة/التقييم من إدارة التطبيق.

### شروط المركبة
1. سنة الصنع لا تزيد عن 10 سنوات (`MAX_AGE_LIMIT`).
2. فحص فني دوري ساري.
3. تأمين إلزامي ساري.
4. لوحات سورية مسجّلة باسم السائق أو بتفويض رسمي.
5. صالحة لنقل الركاب (سلامة فرامل/إطارات/إضاءة، عدد مقاعد لا يقل عن 4).
6. صور واضحة للمركبة من الأمام والخلف ورقم اللوحة.

### البيانات المجمّعة (Payload)
عند الإرسال يُبنى كائن:
```
{
  driver:  { name, id, birth, phone, city, license, licenseExpiry },
  vehicle: { type, model, year, plate, fuel, seats, insuranceExpiry, inspectionDate }
}
```
يُرسل حالياً إلى `console.log` (نموذج أولي بدون خادم). لاحقاً يُربط بقاعدة بيانات/خادم (API).
