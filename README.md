# تطبيق «أُجَرَه» (Ajarah)

منصة توصيل ركاب داخل الجغرافيا السورية، تحاكي فكرة تطبيق أوبر (Uber) ولكن مخصّصة للمدن والطرق السورية.

## الهدف
- ربط الركاب بالسائقين داخل سوريا.
- حساب المسافات والأجور بناءً على جغرافيا المدن السورية (دمشق، حلب، حمص، حماه، اللاذقية، إدلب، درعا، دير الزور، الرقة، الحسكة، القامشلي، طرطوس، السويداء، القنيطرة...).
- واجهة عربية RTL مريحة.

## الحالة الحالية
نموذج أولي (Prototype) بصفحة ويب بسيطة لعرض فكرة التطبيق. سيتم لاحقاً تحديد التقنية النهائية (تطبيق جوال Flutter/React Native، أم موقع ويب).

## التشغيل
افتح ملف `index.html` في المتصفح.

## الخطوات القادمة (مقترحة)
- [ ] تحديد التقنية (ويب / أندرويد / iOS).
- [ ] دمج خرائط حقيقية (Leaflet + OpenStreetMap) مع تركيز على سوريا.
- [ ] شاشة طلب رحلة (انطلاق → وجهة → سعر متوقع).
- [ ] لوحة السائق ولوحة الراكب.
- [ ] الحسابات والمحافظ.
